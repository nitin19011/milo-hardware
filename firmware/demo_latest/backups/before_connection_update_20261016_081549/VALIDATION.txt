with ArduinoJson 7.4.3. The configured TLS/network/acquisition code paths were enabled in compile-only
copies to avoid measuring an optimized build with missing-password branches removed.

Configured code-path build:
  GloveDemo: flash 1,055,616 bytes (80%); static RAM 65,120 bytes (19%).
  MicDemo:   flash 1,040,908 bytes (79%); static RAM 58,184 bytes (17%).
  Mic additionally allocates 96,000 bytes in fifteen 6,400-byte heap blocks for the WAV PCM.
  These are storage blocks, not MQTT chunks; one complete waveform is one QoS1 PUBLISH.
  Driver queues, stacks, Wi-Fi, TLS and JSON use additional heap; live health reports free/minimum heap.
  No external PSRAM is required by the implementation.

Local build helper bypassed Windows flash-image-packaging hooks. C++ compilation/linking succeeded;
normal Arduino IDE upload creates the final flash image. No prebuilt flash binary is distributed.
