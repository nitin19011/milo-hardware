# Printable housings

All available revisions are preserved. Use the individual latest parts below when mixing an updated cap with an already printed base; older combined print plates can contain an earlier cap.

| Assembly | Latest available parts |
| --- | --- |
| Glove ESP + IMU | `glove/Glove_housing_base_v1.stl` and `glove/Glove_housing_cap_v2_deep_skirt.stl` |
| Microphone ESP | `mic/Mic_housing_NECKLACE_v3.stl` and `mic/Mic_cap_v5_split_openings.stl` |
| Sewable flush battery holder | `battery/Battery_flush_sewable_base.stl` and `battery/Battery_flush_cap.stl` |

Read the associated print notes and dimensions for each design. The glove cap's deeper outer skirt improves engagement; the base includes internal sewing points and side wire openings. The mic cap revisions include chip ventilation, reset access and supports to limit movement. The battery variants include end wire clearance and sewable mounting options.

STL dimensions are in millimetres. Fit depends on printer tolerances and the actual hardware. MakerBot jobs in `slicer_jobs` retain their original printer settings; use the STL files to slice for a different printer.

`generation` contains the geometry helpers and historical generator/preview scripts. Run from that folder, with its `work` and `inputs` paths available. Existing final STL files can be printed without running those scripts.
